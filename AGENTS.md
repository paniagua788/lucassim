# AGENTS.md — lucassim.com.py

## Project

Static portfolio + product landing pages. Astro 6, Tailwind CSS 4, TypeScript strict. Deployed to Cloudflare Pages on every push to `main`.

## Commands

```bash
npm run dev       # dev server at http://localhost:4321
npm run build     # production build → dist/
npm run preview   # preview production build
```

No test, lint, or typecheck scripts configured. Run `npx astro check` for type validation if needed.

## Architecture

```
src/
  pages/
    index.astro          # Home — personal intro + product cards
    portfolio.astro      # Portfolio page (separate layout)
    slotr.astro          # Slotr landing page (bento grid, animated hero)
    vareapp.astro        # VareApp landing page (bento grid, animated hero)
  components/
    CategoryCard.astro   # Bento grid category card (used by slotr)
    ProductCard.astro    # Product card on home page
    ContactButtons.astro # WhatsApp + Email buttons
    Navbar.astro         # Fixed top nav
    Footer.astro         # Footer with socials
    icons.ts             # Slotr SVG icons (17 Lucide-style)
    vareapp-icons.ts     # VareApp SVG icons (11 feature + 5 hero food)
    portfolio/           # Portfolio-specific components
  layouts/BaseLayout.astro  # Shared HTML shell, imports global.css
  styles/global.css      # Theme tokens, animations, utility classes
```

## Key Conventions

- **100% static Astro** — no JS runtime, no backend logic, Cloudflare Pages compatible
- **No emojis as icons** — use SVG from `icons.ts` or `vareapp-icons.ts`
- **Hero animations** use shared `hero-float` keyframes with `.hero-shape`, `.hero-icon-float` classes
- **`prefers-reduced-motion`** disables all hero animations
- **Bento grid pages** (slotr, vareapp) use `grid-cols-1 lg:grid-cols-12` with span lookup maps
- **`FeatureCard.astro` is dead code** — removed, do not recreate
- **Navbar/Footer** on product pages: no `showBack` or `showHomeLink` props

## Icon Systems

Two separate icon files, do not merge:

| File | Purpose | Count |
|---|---|---|
| `src/components/icons.ts` | Slotr features + hero | 17 icons |
| `src/components/vareapp-icons.ts` | VareApp features + hero food | 16 icons |

Both export `as const` objects with derived `IconName` types. Use `set:html={icons[name]}` in Astro templates.
